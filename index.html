어떤 서비스부터 시작하면 되나요?

독립적인 인프라가 필요하면 기업 전용 네트워크를, 기존 시스템에 자산 발행이나 컨트랙트 실행을 연결하려면 토큰화 API를 먼저 확인하세요. 서비스별 용도 보기

24시간 안에 네트워크가 구축되나요?

네트워크 생성은 신청 정보의 내부 확인 후 24시간 이내 진행을 기준으로 안내합니다. 필요한 설정과 운영 조건은 신청 전에 확인해 주세요. 네트워크 구축 조건 보기

기존 시스템이나 스마트컨트랙트와 연동할 수 있나요?

EVM 호환 네트워크와 REST API를 제공합니다. 기존 시스템의 구성에 맞춰 호출 방식과 컨트랙트 연동 범위를 확인할 수 있습니다. API 동작 흐름과 사용 예시 보기

어떤 보안 구조를 사용하나요?

AES 기반 암호화, Vault 키 관리, HSM 내부 서명으로 역할을 나눈 보안 아키텍처를 안내합니다. 서비스에 적용할 범위와 운영 환경은 도입 시 확인할 수 있습니다. 보안 아키텍처 확인

도입 비용과 MST 담보 조건은 어떻게 되나요?

전용 네트워크는 MST를 담보로 개설하며, 수수료와 확장 비용도 MST 기준으로 안내합니다. 필요한 구성과 운영 범위에 따라 조건이 달라질 수 있으므로 도입 전에 확인해 주세요. 서비스 개요와 정책 보기

도입 전에 무엇을 준비하면 좋을까요?

서비스 목적, 필요한 기능, 기존 시스템의 연동 방식과 희망 일정을 정리해 주세요. 네트워크 신청 시에는 회사명, 연락처, MST 예치 수량과 기타 요청사항을 입력합니다.
