플랫폼 보안 (Protect)

AI 모델 IPFS 보안 등록 API

AI 모델 파일을 IPFS 분산저장소에 등록하고
블록체인 기반 소유권·무결성 증명을 자동화하는 보안 API

서비스 개요

AI 모델의 안전한 보관과 소유권 증명

접근제어 및 암호화 적용으로 허가된 사용자만 모델 열람 및 다운로드가 가능하며, CID(IPFS 콘텐츠 식별자)의 블록체인 저장 시점 타임스탬프 기록을 통한 소유권 증명 기능을 제공합니다.

핵심 기능

3가지 핵심 보안 기능

탈중앙화 분산 저장

학습 완료된 AI 모델을 AES-256 암호화 후 IPFS 네트워크에 분산 저장하여 단일 서버 해킹, 서비스 중단으로 인한 모델 소실 위험을 차단합니다.

콘텐츠 해시 기반 무결성 검증

IPFS CID(콘텐츠 식별자) 자동 생성 및 블록체인 온체인 기록을 통해 모델 파일의 위변조 여부를 언제든 즉시 검증할 수 있습니다.

접근제어 및 암호화

등록된 모델에 대한 접근 권한을 API 키 단위로 세분화하여 외부 유출 없이 안전한 모델 공유 및 협업 환경을 구성할 수 있습니다.

주요 특징

왜 IPFS 보안 등록이 필요한가

온체인 소유권 증명

온체인 타임스탬프 및 소유권 증명으로 AI 저작권 침해 분쟁 시 법적 증거 자료로 활용 가능

버전 관리

모델의 학습 이력과 버전을 체계적으로 관리하여 특정 시점의 모델 상태를 추적·복원 가능

위변조 방지

블록체인에 기록된 CID와 비교하여 모델 파일의 무단 수정 여부를 실시간 탐지

보안 유지

AES-256 암호화 및 API 키 기반 접근 제어로 모델의 기밀성 보장
